# Icons folder

Drop your app icons here using the **same filenames** referenced in `script.js`,
for example: `settings.png`, `wifi.png`, `gmail.png`, `chrome.png`, etc.

- Recommended size: 128×128 or 192×192 PNG (square, transparent background)
- If an icon is missing, the launcher automatically shows the first letter of
  the app name as a fallback — so the layout never breaks.

You can rename files freely — just update the matching `icon:` path in `script.js`.
